# Bunny Up 🐰

Bunny Up is a vertical 2D platformer developed in Godot as my first independently built game project.

Climb through six themed sections while navigating different platform mechanics, enemies, environmental hazards, and collectibles.

## Features

- Six themed vertical sections
- Moving, breakable, sinking, and slippery platforms
- Multiple enemy types
- Health and damage system
- Coins and score system
- Wind and snow environmental effects
- Spring platforms
- Jetpack mechanic
- Game over and win system

## Built With

- Godot 4
- GDScript
